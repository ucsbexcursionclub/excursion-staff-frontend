# Update Log — November 11, 2026

**Author:** Noah Kovach

---

## Summary

Two gear management additions: a rental history for each gear item, and a bulk action to set "Last Contacted" to today for several checked-out items at once. Requires the matching backend branch (`noah/gear-history-bulk-contacted` in `excursion-backend`), which must be deployed first.

---

## 1. Rental History Per Gear Item

**Files:** `CheckoutHistory.tsx`, `ReservationProvider.tsx`, `utils/utils.ts`, `utils/types.ts`

- The History tab in the gear details dialog now lists every rental of that item, newest first, with the member's name, checkout date, return date and number of days.
- Rentals still out show the due date, days so far, and a "Checked out" or "Overdue" chip.
- The backend now records `checked_out_at` on each reservation and a per-item return time in `gear_returned_at`. Rentals returned before this change have no return time and show "Returned: not recorded"; their checkout date is read from the reservation's ObjectId timestamp (`getReservationCheckoutTime`).
- Fixed `retrieveReservationsByGearId`, which never matched a reservation that was still checked out.
- Removed the "View Member" and "View Reservation" buttons, which did nothing.

---

## 2. Bulk "Mark Contacted"

**Files:** `GearNav.tsx`, `GearMarkContactedDialog.tsx` (new), `GearProvider.tsx`, `utils/api.ts`

- New "Mark Contacted" button in the gear nav. Select gear rows, click it, and confirm to set Last Contacted to today on each item's current reservation.
- Applies to any selected item that is checked out, overdue or not. Items that are not checked out are skipped, and the dialog says how many.
- Uses one request: `PATCH /api/v1/reservations/bulk-last-contacted` with `{ids}`. The server sets the time.
